# First Investigation datasets

Small synthetic datasets for the Academy and Google Colab.

All names, handles and activity are fictitious. IP addresses use documentation ranges from RFC 5737 and the domains use `example.org`.

## Tracks

| File | Track | Focus |
|---|---|---|
| `dfir.csv` | DFIR | process, network, service and logon timeline |
| `osint.csv` | OSINT | grounded entity extraction, normalization and graph semantics |
| `hybrid.csv` | DFIR + OSINT | combine host telemetry and public-source-style mentions |

These files are intentionally tiny. They exist to teach method and to keep the first Colab investigation fast on CPU.
