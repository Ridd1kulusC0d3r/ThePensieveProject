# Google Colab

Abra `colab/pensieve_dfir_osint.ipynb` no Colab.

O notebook foi deliberadamente dividido em duas velocidades:

1. **Core**: instala o projeto, ingere um laboratório sintético, extrai entidades determinísticas, monta o grafo e gera o dashboard.
2. **Modelos opcionais**: GLiNER e Qwen só são instalados quando seus toggles são ativados.

Isso mantém o primeiro laboratório utilizável em CPU e evita transformar “leve” em uma palavra decorativa.

O notebook usa o repositório GitHub como origem. Em forks, altere a URL da célula de instalação.
