# Datasets e fontes de laboratório

O catálogo machine-readable está em `datasets/catalog.json`.

| Fonte | Uso principal |
| --- | --- |
| NIST CFReDS | imagens/cenários documentados, treinamento e validação |
| OTRF Security-Datasets | telemetria e correlação |
| EVTX-ATTACK-SAMPLES | validação do parser EVTX e exercícios de Event IDs |
| ForensicArtifacts | definições YAML de artefatos |
| Plaso | benchmark e interoperabilidade |
| Dissect | backend opcional de imagens/artefatos |

Não redistribua datasets sem conferir os termos de cada fonte. O catálogo registra uma nota de licença, não substitui a licença original.
